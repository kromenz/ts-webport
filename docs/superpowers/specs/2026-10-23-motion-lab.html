Motion Lab_

16 ideias de animação para o teu portfolio, todas a correr ao vivo com o teu verde, as tuas fontes e os teus dados. Experimenta cada uma, marca "quero isto" nas que gostares e escolhe uma direção no fim. O botão em baixo copia a lista para colares no chat.

biblioteca
Manter o framer-motion e juntar anime.js 4.5 (MIT), importando só os módulos usados: cerca de 15–26 KB.
direção
As pesquisas apontam para B + C: estrutura limpa de shell moderno, com um campo ASCII vivo como assinatura no hero. O CRT fica como easter egg.
evitar
Intro com mais de 1,5 s, matrix rain como fundo principal, site em que só se navega a escrever comandos, vários canvas a correr ao mesmo tempo.
O teu sistema pede menos movimento. As animações contínuas estão paradas: carrega em ↻ repetir para ver cada uma.
O anime.js não carregou, por isso algumas demos não vão animar. Recarrega a página.
